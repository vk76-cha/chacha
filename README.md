# iingamy 的个人名片网页

## 项目介绍

这是我在 Vibe Coding 课程中完成的第一个作品。它是一个个人名片网页，用来展示我的昵称、喜欢的内容，以及一些有趣的互动。页面的整体感觉是绿色、手绘星星和一点点梦幻感。

## 如何运行

下载或打开这个项目文件夹后，直接双击 `index.html` 就可以在浏览器中打开。

这个网页不需要安装依赖，也不需要运行 npm。因为背景图、CSS 和 JavaScript 都已经放在 `index.html` 里，所以离线也可以查看。

## 已完成功能

- 展示昵称 iingamy
- 展示一句话介绍“她转过来。”
- 展示补充文字“幸好 世界上有明亮的春天 勇气 自由  咖啡和面包 还有小动物和好天气。”
- 展示兴趣标签 Formula 1、Music、Taekook
- 使用绿色手绘星星风格的背景
- 可以切换日间模式和夜间模式
- 页面上有可以点击的手绘星星，点击后会出现对应留言内容
- 点击 Connect Me 可以打开个人联系卡片
- 点击 Leave Message 可以打开留言界面
- 提交留言后，页面会生成一颗新的留言星星
- 点击新增的留言星星，可以查看刚刚写下的留言
- 留言星星的内容弹出后，可以点击 Delete 删除不想要的留言
- 留言会保存在当前浏览器中，刷新页面后还能继续看到
- 页面在手机宽度下会自动调整布局
